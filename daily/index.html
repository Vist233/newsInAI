Insight

今天这批条目最清晰的共同主线，不是“AI又赢了”，而是自动化叙事与工程现实之间的落差。AI agent 能报出未绘制的玛雅遗址、接管会话、操作浏览器，甚至被讨论用于订票，但 United 的反向禁令、codex-security 和 MCP 类项目都在提醒：权限、责任、审计和失败模式才是落地门槛。另一边，烟雾报警器差点淹掉 Jane Street 唯一的纽约数据中心、用电压毛刺解锁 A100、AWS 模拟器和 WebGL 沙子，说明真正稀缺的仍是可靠系统、硬件知识和可复现实验。Tim Peters 的离世也让这种工艺传统显得更重。被高估的是“通用 agent 即插即用”的想象：多数演示把模式识别、脚本编排和人工兜底包装成自主性，把发现故事浪漫化。短期内更值得押注的是受限场景、明确权限和可验证输出，而不是无所不能的代理。
